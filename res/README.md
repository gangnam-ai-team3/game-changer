# res 작업 칸

- 담당자: 유주심
- 담당 범위: 근거 구조화와 시스템 통합
- 참고 교안: Day7 4쪽, 17~19쪽

이 폴더는 유주심 담당 에이전트의 실습 자료와 제출물을 보관합니다. 실제 회사 자료 대신 합성 자료만 사용합니다.

| 파일 | 용도 |
| --- | --- |
| `agent-spec.md` | 교안의 개인 명세서 여섯 칸을 정리한 제출물 |
| `input-sample.md` | 에이전트에 넣어 볼 합성 변경안과 피드백 |
| `stub.md` | 지난 결과에서 가져온 출력 모양 견본 |
| `result.md` | 입력을 검사하고 구조화한 실습 결과 |

실습 순서는 `input-sample.md`를 읽고 `stub.md`의 모양으로 결과를 만든 뒤, `result.md`에서 오류와 판단 근거를 확인하는 것입니다. 표본이 부족한 결론은 만들지 않고 숨긴 이유를 적습니다.
