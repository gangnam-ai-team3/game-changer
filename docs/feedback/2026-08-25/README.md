# 2026년 8월 25일 개선 제안 반영 기준

정아현, 정현예 팀원이 전달한 Notion 내보내기 원본은 로컬 `.data/feedback/2026-08-25/`에 보관하고 Git에는 포함하지 않습니다. 이 문서에는 제품에 반영할 요구사항과 보류 범위만 정리합니다. 제안서 화면의 예시 수치와 타사 사례는 디자인 참고용이며, 게임체인저의 분석 결과로 사용하지 않습니다.

## 이번 버전에 반영하는 내용

- 첫 화면을 `동향 추출`과 `예상 시나리오 점검`으로 구분합니다.
- 동향 추출은 사전 구축 Steam 코퍼스에서 감정 분포, 주요 주제, 언어별 표본, 분류 신뢰도를 보여줍니다.
- 예상 시나리오 점검 안에서 이벤트와 업데이트 유형을 선택하도록 구성합니다.
- 결과는 핵심 요약, 데이터 범위, 세부 분석, 위험과 대응, 상세 근거 순으로 정리합니다.
- 현재 저장된 데이터에서 계산할 수 없는 값은 임의로 만들지 않고 `데이터 연동 필요`로 표시합니다.
- 브라우저의 인쇄 기능을 이용해 결과를 PDF로 저장할 수 있도록 합니다.
- 장식용 자동 애니메이션은 추가하지 않습니다.

## 후속 데이터 연동이 필요한 내용

- 날짜별 반응 변화와 자사 평시 기준선
- 과거 유사 사례의 실제 성과와 유사도
- 리뷰 폭탄 탐지와 봇 제거 통계
- 매출, 결제, 이탈 지표
- 판정 사후 적중률
- 이미지, 영상, 표를 포함한 기획안 파일 분석
- 선택한 섹션만 별도 파일로 내보내는 기능

이 항목은 데이터 계약과 출처가 마련된 뒤 추가합니다.
