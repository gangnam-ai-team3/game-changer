# 입력 형식과 예시

## 입력 형식

- 리스크 서술 — 앞 단계가 정리한 이번 업데이트의 핵심 리스크. 3~6문장이며, 어떤 변경이 어떤 플레이어 모델에게 어떤 마찰을 일으키는지 포함합니다.
- 검증·개선이 필요한 항목의 나열. 항목마다 아래 4개 필드를 가집니다.
  - 항목명: 무엇을 고쳐야 하는지 한 줄
  - 담당자: 실행 책임자 이름 또는 역할
  - 기한: yyyy/mm/dd 형식의 날짜
  - 근거 ID: 이 항목을 만든 VOC 증거의 식별자 목록

필드가 비어 있어도 접수는 거부하지 않습니다. 비어 있다는 사실 자체가 반려 사유로 기록될 뿐입니다.

## 입력이 비었을 때

확인할 대상(리스크 서술 또는 항목 목록)이 없으면 "확인 대상 없음"으로 표시합니다.

이 문구를 쓰는 경우는 아래와 같습니다.

- 항목 목록이 비어 있음
- 리스크 서술만 오고 항목 목록이 오지 않음
- 항목은 있으나 항목명이 전부 비어 있어 판정 대상이 성립하지 않음

이때 추측으로 항목을 만들어 채우지 않습니다. 리스크 서술에서 할 일을 유추해 표를 만드는 것은 금지입니다. 헤더만 있는 빈 표도 내놓지 않습니다.

## 예시 (샘플 — 실제 데이터 아님)

> 이 파일의 내용은 형식을 보여주기 위한 예시입니다. 실제 VOC·리스크 데이터가 아닙니다.

### 리스크 서술

이번 업데이트는 확률형 아이템의 확률 표기 위치를 상점 첫 화면으로 옮기고, 한정 아이템 구매 시 중복 보호 장치를 새로 추가하며, 주간 참여 조건을 완화하고, 번들 가격 구간을 재조정합니다. 확률 표기 변경은 고지 의무에 민감한 플레이어 모델(신규 결제 플레이어)에게 신뢰 마찰을 줄이는 방향이지만, 표기 위치 이동 자체가 기존 구매 플레이어에게는 익숙한 동선을 깨는 마찰이 될 수 있습니다. 중복 보호 장치는 한정 아이템을 반복 결제하던 플레이어 모델과 직접 충돌합니다. 주간 참여 조건 완화와 번들 가격 재조정은 라이트 유저의 이탈 마찰을 낮추는 것이 목적입니다.
