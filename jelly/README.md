# jelly 작업 칸

- 담당자: 정아현
- 담당 범위: 업데이트 및 콘텐츠 위험 진단

이 폴더는 정아현 담당 에이전트의 실습 자료와 제출물을 보관합니다. 실제 회사 자료 대신 합성 자료만 사용합니다.

| 파일 | 용도 |
| --- | --- |
| `agent-spec.md` | 교안의 개인 명세서 여섯 칸을 정리한 제출물 |
| `input.md` | 동향 입력 표 모양 |
| `stub.md` | 동향 분류·신뢰도 계산·그룹핑 규칙을 정리한 모양 견본 |
| `result.md` | 입력을 분석해 구조화한 실습 결과 모양 |

실습 순서는 `input.md`에 근거를 채우고 `stub.md`의 규칙으로 분석한 뒤, `result.md` 모양대로 동향 요약·동향 그래프·콘텐츠 별 동향 분석·종합을 만드는 것입니다. 근거 내용이 없으면 "근거 부족"으로 남기고 지어내지 않습니다.
